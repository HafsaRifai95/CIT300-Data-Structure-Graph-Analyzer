## 1. Project Description

## 6. Algorithm Complexity

| Algorithm | Typical Time Complexity |
|---|---|
| Array access by index | O(1) |
| Linear Search | O(n) |
| Binary Search on a sorted array | O(log n) |
| Stack push/pop | O(1) |
| Queue enqueue/dequeue | O(1) |
| BFS | O(V + E) |
| DFS | O(V + E) |

**Notation:**
- `n` represents the number of elements.
- `V` represents the number of graph vertices.
- `E` represents the number of graph edges.

Actual performance depends on the implementation and input data.
